# 看板 API 错误契约

## 适用范围

本契约适用于本地 `V1.3.1` 和妙搭 App 的 `GET /api/data`。错误响应统一使用：

```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "可直接定位问题的中文说明"
  }
}
```

## 状态码对标

| HTTP 状态码 | 业务码 | 含义 | 典型场景 |
|---|---|---|---|
| `422` | `VALIDATION_ERROR` | 已识别的数据契约不满足 | 总表必需字段缺失、筛选字段缺失、命中子任务未关联父记录、没有符合筛选条件的子任务 |
| `503` | `SERVICE_UNAVAILABLE` | 上游数据源或运行配置暂不可用 | Base OpenAPI／lark-cli 请求失败、网络失败、凭据或环境变量不可用、分页响应异常 |
| `500` | `INTERNAL_ERROR` | 未预期的软件异常 | 未被业务分类的代码错误；必须保留服务端日志，不向前端泄露堆栈 |

`500` 只用于未知异常。已经识别为字段或记录结构问题的异常必须返回 `422`，不得再以“服务器内部错误”掩盖根因。

## 字段缺失降级

- 总表必需字段缺失：返回 `422`，整次刷新失败，继续显示上次成功数据。
- 「价值决策／TDR1计划／TDR1实际／TDR2计划／TDR2实际／TDR3预计／TDR3实际」缺失：返回 `200`，对应数据值以及可见表头／阶段标题为空白；TDR1／TDR2／TDR3 任一计划或实际源字段缺失时，该阶段标题为空白。
- 「专一／专二／专三／专四／验收」不属于看板映射，不参与校验或渲染。
- 视图名称不参与校验；URL 中有效的 `table_id` 与 `view_id` 才是配置契约。
